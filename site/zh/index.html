A negative answer to Question 31 (section 2.2.5, page 24, arXiv:2610.22248v1): special linear obstructions for evolution algebras

Haobo Ma, Wenlin Zhang

论文

每一种代数群，能否成为某个乘法特别稀疏的代数的全部对称群？马浩博与张文林对有限维复演化代数给出否定答案，排除了大多数特殊线性群。关键是分类这种乘法所允许的无穷小对称性。

演化代数有一组基，不同基向量相乘为零，其余乘法由各自平方确定；不要求结合律或单位元。保持乘法的可逆线性映射称为自同构，无穷小对称性称为导子，满足 D(xy) = D(x)y + xD(y)。导子以复合之差 DE − ED 为括号构成李代数。实现问题见于 Kaygorodov、Martín González 与 Viruel 的综述，原归于 Costoya 和 Viruel，区分抽象群、代数群及群概形。后两者保留几何结构；沿用 Elduque 与 Labra 的切空间观点，作者利用其同构必然诱导导子李代数同构这一事实。

对称双线性型是对称且对每个变量都线性的标量配对；非退化指没有与所有向量配对均为零的非零向量。保持它的无穷小变换组成正交李代数 so_m，其中 m 是空间维数。作者分类的是半单导子李代数，即没有非零可解理想的导子李代数；可解意味着反复取交换子最终为零。在代数闭的零特征域上，所有可能恰是有限个 so_m 的直和，其中 m 至少为三，也允许零代数。这证明综述的猜想5，并且只解决问题36的半单部分。

证明先说明半单性迫使零化子为零；零化子由与所有向量相乘均为零的向量组成。否则，取值于其中的映射会产生不允许的可解理想，或迹非零的导子。再按基向量平方是否成比例分组，缩放使组内平方相同。乘积法则禁止导子混合不同组，并迫使组内非对角元互为相反数；半单性消去对角标量项。各组于是承载斜对称算子，还须消去共同平方的指定投影。这些逐点稳定子满射到正交李代数，其幂零核被半单性排除。

行列式为一的群 SL_n，其无穷小代数 sl_n 由迹为零的矩阵组成。sl_3 是八维，而足够小的允许正交项只有三维和六维，无法相加得到八。比较秩与维数还排除所有至少为五的 n。例外 sl_2、sl_4 分别同构于 so_3、so_6，能成为导子代数，却不表示 SL_2、SL_4 能成为完整群。无穷小的乘法保持条件正是导子法则，故障碍传到群概形；Cartier 的零特征光滑性定理将其传到代数群，但不能传到抽象群同构。

实现采用综述已有的正交构造：在带对称型 b 的空间 V 外加入向量 u，令 u² = u、uV = 0、vw = b(v,w)u。完整自同构群就是该型的等距群，取直和可实现分类中的导子代数。二维例子 u² = e² = u、ue = 0 只有两个自同构，但每个正整数 t 都给出自然基 u + te、−tu + e。允许交换和分别缩放后，不同参数仍不等价。作者承认代数及群已有前人研究；这里解决了问题14中零化子为零、群有限而自然基类别无限的存在部分，且二维最小。

作者还证明，零化子为零时，导子代数除去最大可解理想后的半单商仍为正交直和。因此 sl_3、例外李代数 g_2 不能成为简单理想，却不排除子代数：sl_3 在三维空间及其对偶上的忠实作用保持对称配对，能嵌入 so_6。反之，三维零乘法代数的所有线性映射都是导子，其导子代数确有简单理想 sl_3，故零化子条件不可删。

这些结论依靠书面证明，非有限测试外推。手稿报告的 Lean 证据涉及半单分类、SL_3 的切空间桥梁及群概形障碍、二维自然基存在性，不含最小性；商代数与较大 n 的结论由书面证明给出。计算仅检验到正交维数七、秩比较的 n 为100、基参数25，不能证明无限范围结论。抽象群问题、SL_2 与 SL_4 的完整群实现、正特征、可解或幂零情形的实现均不在结论之内。
